Tiny Birthday World - source package

Files:
- index.html  : page content / text
- style.css   : colors, fonts, layout, animations
- script.js   : quiz logic, page switching, moving NO button, gift interactions

How to preview:
1. Keep all files in the same folder.
2. Double-click index.html.
3. It will open in your browser.

Where to edit:
- Change wording/text mainly in index.html
- Change colors/fonts/background/spacing in style.css
- Change quiz answers and interactions in script.js

You can also use the included single-file HTML version if you prefer everything in one file.
